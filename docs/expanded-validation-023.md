# Expanded local validation, v0.23.0 candidate

This iteration adds four papers to the original hydrogel example and the four biological/ML readings, for **nine unique papers**. English and Chinese hydrogel readers are the same source paper and are not counted twice. Nothing is published or changed in the pending marketplace listing by this local test.

| New paper | Reasoning tested | Decisive reading difficulty |
| --- | --- | --- |
| [PORTAAL classroom practices, PLOS One 2026](https://doi.org/10.1371/journal.pone.0327269) | Observational | Records versus people; crossed clusters; PCA axes; adjusted non-monotonic associations; unmeasured confounding |
| [Active-learning meta-analysis, Higher Education 2023](https://doi.org/10.1007/s10734-022-00977-8) | Evidence synthesis | Papers versus estimates/participants; standardized effects; subgroup uncertainty; funnel diagnostics; source inconsistencies |
| [Sjödin, short FTA proof, fixed arXiv v1](https://arxiv.org/abs/1305.7077v1) | Purely theoretical | Quantified local lemma; normalization; conjugation lost in extraction; explicit reader-derived radius repair |
| [Hicks et al., conceptual argument, 2024](https://doi.org/10.1007/s10676-024-09775-5), with [official correction](https://doi.org/10.1007/s10676-024-09785-3) | Interpretive/conceptual | Definition and attribution; objections; conditional stronger conclusion; a repository copy predating correction |

The new papers are development cases read during this iteration, not untouched holdouts. The cases are authored with same-agent source-first second review. There is no new model benchmark, independent forward execution or human comprehension measurement. Six routes now have worked reasoning examples, but a single case does not validate an entire discipline or all papers within a route.

Two software defects were reproduced as failed checks before repair: scientific prose could skip claim coverage when labeled navigation, and JATS evidence could cite a nonexistent/wrong section because only whole-document quote presence was checked. The new tests reject those cases and accept a valid anchor. The gate still does not judge scientific entailment or detect every misleading heading.

The review instructions now distinguish extraction error, reported source claims, author interpretation and reader-derived algebra. Original files remain unchanged. Source conflicts are visible in local companions and review records; a repair is not falsely attributed to the author. The selected observation-table rows are checked against original structured data, and teaching calculations are separately labeled as calculations, not study reproduction or formal verification.

The original prose-first canvas, left/right branches, story map and separate research argument graph remain shared across all cases. Actual Chrome paths check branches, evidence targets, source links, narrow layouts and native equations/quotations. Detailed run evidence and lawful local research sources remain in the maintenance task folder; original new PDFs are not included in the importable Skill ZIPs.

Next quality work should use fresh papers and independent subject/model execution, especially longer proofs, qualitative empirical research, non-educational observational studies and other review designs. Do not equate passing hashes, UI checks or a larger sample count with guaranteed reading correctness.
