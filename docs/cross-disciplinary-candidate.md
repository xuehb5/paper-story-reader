# v0.22.0 candidate: what is being expanded

This is a local development iteration, not an assertion that every discipline or model is validated. Public v0.21 downloads and the pending marketplace submission remain unchanged.

The product remains a source-faithful explanatory companion, with substantial prose on one pannable/zoomable paper, meaningful left/right branches, a synchronized story map and a separate research argument map. It is not being replaced by a generic summary or a figure gallery.

## Core and profiles

Select the actual study type before designing the story. Experimental, computational, observational, theoretical, evidence-synthesis and interpretive routes can be composed for mixed reasoning. Disciplines are separate labels. Materials/chemistry retains the earlier specimen, normalization and structure–property checks; the universal core does not delete those checks.

The input can now express tables, equations/definitions and short original quotations. They participate in the same evidence index, source links and review ledger as figures. DOI is optional; original sources still require provenance. A material inventory distinguishes a missing attachment from one confirmed unpublished or inapplicable.

## Evaluation design and limits

1. Preserve the existing Chinese and English hydrogel examples as regressions.
2. Use CAHS protein networks (Tanaka et al., PLOS Biology 2022, 10.1371/journal.pbio.3001780) and LoRA (Hu et al., arXiv:2106.09685v2) as development readings.
3. Freeze the initial Skill/reference instructions before reading the substantive arguments of Dsup (Chavez et al., eLife 2019, 10.7554/eLife.47682) and RMSNorm (Zhang and Sennrich, arXiv:1910.07467v1), then author transfer readings with the same instructions. Abstracts/identity were used beforehand to select these papers.
4. Keep source-quality review, mechanical validation and real browser checks separate. These are same-agent authored and second-pass-reviewed examples. They do not demonstrate autonomous execution by another model, blind evaluation or improved human comprehension.

The first real transfer scope is biological experiments and machine-learning papers, including a mixed computational/algebraic argument. Pure mathematics, observational social science, humanities interpretation, systematic reviews and clinical work have not received real-paper validation in this iteration. Synthetic tests exercise their data contracts only; do not market them as domain evaluations.

The local readers preserve complete original views and original source links. Paper coverage is stated inside each companion. Unread SI is not called absent. In particular, the CAHS AFM timing discrepancy is disclosed rather than silently reconciled; LoRA's smaller WikiSQL score and base-model storage remain visible; Dsup separates new biochemical evidence from cited earlier cell results; RMSNorm keeps the positive-scale/nonzero-denominator conditions of the explained cancellation argument.

The local sample collection is separate from the importable Skill. Original arXiv PDFs/images are retained locally for research reading, not included in the public package or treated as freely redistributable. A future public example requires appropriate source permission and attribution.

## Before a stable cross-disciplinary release

Run complete package/extract/render checks, retain the original bilingual UI regressions, and test representative papers per additional route. Compare explanations against original sources and obtain subject-reader feedback. If a holdout exposes a rule defect, report the change and use a fresh holdout; do not present a tuned rerun as untouched validation. Runtime-only UI fixes should be reported separately from prompt changes.
