## 中文短介绍

读论文最费时间的，往往是把“作者为什么这样做”和“这张图到底支持什么”串起来。

我把自己的材料、化学论文阅读流程做成了开源 Skill：**PaperStory｜论文故事线**。它让 Agent 联合主文和同篇 SI，先组织有原文依据的研究故事，再生成离线交互读本：正文是主干，复杂解释在左右侧枝，脑图与研究论证图可定位到正文，图像可回看来源。

可直接体验真实水凝胶论文示例，也可下载 Skill 处理自己的论文。代码与指令采用 MIT，示例材料保留原文许可。它还需要 Agent 回源核查，不把自动校验当作科学正确性保证。欢迎用具体论文报告误读和交互问题。

## English introduction

**PaperStory** is an open-source Agent Skill for experimental materials and chemistry papers. It connects the main article and its own Supporting Information into a source-grounded research story, then renders an offline reader with synchronized mind-map navigation, an argument graph, original figure links, and a zoomable canvas with left/right explanation branches.

Try the real hydrogel-paper demo or import the Skill into your local Agent workflow. Code and instructions are MIT licensed; scientific example materials retain their original license. Evidence checks help detect stale records and missing sources, but do not certify scientific correctness. Concrete paper-level feedback is welcome.
