# 原文本身有疑点时怎样讲清楚

遇到公式、版本、计数或关键比较不能自洽时读取。

先区分提取错误和印刷问题：查看原页的正负号、共轭横线、指数、单位、图例与脚注，再判断；不要从纯文本猜公式并直接修正。保存原始文件和版本，必要时读取官方更正，仓储 PDF 可能早于更正。

明确分开原文报告、读者解释和读者为教学做的推导/修补。后者注明身份并验证，不改原图，不冒充作者结果。原文展示证明不等于我们独立认证证明有效；影响推理的问题必须可见，不为了故事顺滑掩盖。使用现有 qualified 单元和未决来源问题记录。

观察性研究区分独立人数、重复记录、课程或机构等聚类层级。调整协变量不自动产生随机干预的因果解释；不显著不等于零效应，中间组为正不等于单调剂量反应。综述区分论文数、效应估计数与参与者数，保留效应量单位、方向、异质性与不确定性。偏倚调整接近原值不证明不存在偏倚。原文记号或流程计数冲突不得默默重构成整齐数字。

概念论证保留作者归属、定义、反对意见及条件分叉。示例不是新实验，类比不是证明，有争议的强论断不能替换原文较弱的结论。

账本尽量引用最小有用段落。JATS 有稳定元素 ID 时，文字证据增加 `anchor`，程序会在该元素内核对引文；`locator` 继续用于人工说明。正文、表格单元格、公式、图注、图谱 finding 不能改标为 navigation 绕过事实覆盖；标题是否夸大仍需人工判断。

原文链接也须方便阅读：若 JATS 用于机器复核，同时有匹配的原始 PDF，表格或公式的阅读链接优先指向核实后的 PDF 物理页，避免要求读者在 XML 中找数据。保留 JATS 锚点证据，不给它编造 PDF 页码。
