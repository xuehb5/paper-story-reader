# 以正文为主的读本与流程导航

## 正文的完成标准

完成必须同时满足来源忠实和解释充分。正文应让读者理解，而不是仅让审核者找到已限定的语句。先组织一段关键转折的样章作为全文的内部质量基准：已有认识、当前疑问、设计/测试的理由、实际图证、读图观察、判断及下一步，按实际需要分到主干和侧枝。不是先搭七个标题、填几段摘要，再补审核账本。

读者即使不点击图谱，也应能沿正文理解问题的来由、设计与实现、表征/测试为何必要、关键发现、解释与适用范围。段落自然衔接，标题依论文具体问题命名。少量表格用于比较样品或指标，不用表格/卡片填满全文。

对每项决定性实验或表征，讲清它在当前阶段回答什么、为什么采用它、如何看关键观察，以及观察怎样支撑下一步判断。只介绍仪器能测什么不够；不需要详细参数时也不要改写成实验操作手册。

概念在第一次影响理解的位置补足。可以用类比或小算例，但注明教学性质并尽快回到真实对象。保留论文的具体设计选择与对照，不泛写成任何论文都适用的教材段落。

原图与解释放在相邻位置。图之前有问题和阅读提示，图后说明观察与含义；引用位置便于回查。长谱图、详细方法和次要结果可展开，但核心解释与结论无需点击才可读。

## 导航要表达科学关系

流程图表示研究问题的推进，节点与边均应有具体含义。节点可以是“如何确认形成目标网络”“为什么更快的断链没有带来更多目标活化”等问题，按论文实情命名。连线可表示提出设计、形成样品、证据支持、比较或解释，不把阅读先后自动等同于因果。

保留必要分支。多个表征共同支撑一个判断时可汇合；结构和功能的两条证据可分别展开后汇合。不强制固定节点数、线性七步或逐图一节点。

在正文草稿形成后建立定位关系，再核查图谱是否暴露了正文遗漏的解释。允许据此迭代正文；没有解释的空节点不能成为完成品。

## 复合图的阅读单元

### 主线与局部的层级

正文先承担全文的解释：研究起点、解法为何合理、样品与比较为何可信、证据如何回答问题、功能怎样实现，以及结论边界。默认状态下这条链完整可读。关键观察与结论在主线中明确出现，重要图证随论证放置；图的拆解服务于当前转折，不以原图顺序或全局“读图01—21”替代文章结构。

复杂面板的图例、坐标、逐线比较及详细步骤，放入就近的可展开补读。需要这些细节的读者能直接定位；已经理解的读者可继续顺读。主线与补读可以引用同一图证，分别说明论证用途和局部读法，避免把每张图都讲两遍。

侧枝应当完成一个理解任务，不只是把“未证明”“不等于”“不能推出”等限定语搬到旁边。结构如何改变、为何选择对照、某组曲线应怎样比较、SI怎样补齐主文等，都应有针对本文的解释和必要图证。判断边界仍须保留在影响结论的位置，不能为了故事流畅隐藏它；也不能让连续纠错代替研究故事。

对有多个任务的关键复合图，只给全图和压缩图注不足以完成讲解。按当前科学问题安排局部阅读步骤；每步让读者知道看哪里、比较什么、实际看到了什么、这对主线有什么作用。使用 walkthrough、清晰局部与完整图回看；无需拆的图保留整图。重要的设计/合成若原文已有可用结构图，不能只用长段化学名词带过而不给图。图与正文的双向定位是导航目标，不是将图号列入目录就算实现。

脑图优先呈现科学故事，桌面默认可见；节点标出有关图号并定位主线解释。图证索引按同一组研究问题收纳，作为次级入口。验收时同时确认脑图可见、主要论证不藏在折叠区、局部讲解不强迫读者逐条通关。

复合图可以含不同时间、状态、测量和证据层级。先把每块面板在论证中的任务弄清，再安排面向读者的顺序。设计图、参照物和信号判定可能需要分步解释；同一判断所必需的双样品或多条件比较应保持可相互对照。拆出的局部仍属于原图，导读重排不改写论文原有编号。

每个主要阅读单元宜有：原图号/面板或明确的区域名、要回答的问题、起始位置与阅读方向、必要的图例/坐标/样品身份、关键比较和观察、由此得到的判断及与下一单元的联系。这些信息用自然段解释，不必重复固定六列模板。

没有面板字母的图使用“合成上部”“连接对照”等区域名；一幅面板的导读分段注明“上排/下排”“局部”等，不虚构a、b或e1、e2原始编号。重排后尤其检查箭头、时间顺序、共同坐标与颜色图例是否仍可正确理解。

每个局部保留相关图例、坐标、标尺、标签和比较对象；无法用一个矩形同时干净保留这些内容时，宁可保留更大区域或拆成有说明的关联视图，不静默遮盖/移动原图数据。相邻解释之外，提供完整复合图和原页的回看入口。窄面板按实际显示宽度渲染，避免从低分辨率整页截图直接放大。

左侧/上方大纲按阅读逻辑列出“图号/面板＋本步用途”，目标是该处的解释，不是无解释的图片墙。可保留研究关系流程图，并用分组的面板目录承担细节。SI在相应研究问题下出现；其定位应展开必要的折叠祖先，保留键盘焦点和可见落点。

## 两层定位

1. 流程节点定位到生成导读中的实际段落或小节。
2. 该处的图与关键判断定位到原论文正文或SI的实际证据位置。

这是两类不同目标。跳到导读并不等于已跳到原PDF的精确段落；宿主仅支持页码/图号时如实提供可查找位置，不伪造深链能力。

可在内容稿中给解释块分配稳定ID，例如`guide-identity`、`guide-response-comparison`；同一个ID保留在HTML元素与导航目标中。一个节点可连接多个说明块，同一段解释也可被不同问题引用；首个目标作为默认落点。

内部导航记录可以采用以下结构，字段只约束对应关系，不强制特定渲染器：

```json
{
  "nodes": [{
    "id": "identity-question",
    "question": "是否得到了目标结构？",
    "role": "identity",
    "targets": ["guide-identity"],
    "evidence_ids": ["main-fig-identity", "si-confirmation"]
  }],
  "edges": [{
    "from": "design-question",
    "to": "identity-question",
    "relation": "制备后需要确认实际结构"
  }]
}
```

此片段只说明字段，节点和证据不是某篇论文的真实答案，也不是可直接提交的完整数据。实际输出中每个引用都必须存在。

## 当前交互范围

正文占主要阅读区域。紧凑流程图提供全貌与跳转，关键原图可放大，SI补证可展开，来源信息可回查。点击应使对应解释进入视野，并有可见定位或焦点提示；选中态不能只靠颜色表达。

正文是一张连续的二维纸面。主干、左右侧枝、连线始终存在于同一画布，位置固定；默认镜头以可读比例集中主干，侧枝不撑开主干行距。主干按科学问题推进，侧枝在左右纸面提供概念、图解或SI细讲，错开以避免覆盖。入口写明问题、方向与有关图号。

点击侧枝应产生同一视窗中的连续镜头平移与缩放：途中可看见主干、连线、侧枝，随后靠近目标。不得隐藏主干、移走内容节点或切换成另一个阅读区。返回也以镜头动画移回原坐标和比例，保留焦点。空格加拖拽平移、滚轮阅读、缩放和脑图定位均操作这张纸。纸面布局与镜头位置是两套独立状态；验证时必须分别检查，不能用文字标签和位置切换冒充镜头运动。

正文与SI按论证用途共同组织。决定性SI对照可直接进入主线，详细谱图、拟合或方法保留在就近分支。附件内容不因名为SI就全部隐藏，主文面板也不因位于主文就全部摊开。

窄屏使用折叠脑图，继续保留同一张纸；镜头移向目标后，文字在阅读比例下整行可读，外层页面不出现意外溢出。尊重减少动态效果设置。导航不挤压阅读宽度，不要求自由拖拽、3D图谱、在线聊天、账户或云论文库。滚动同步高亮应覆盖上读/下读、页面尾部、分支展开与关闭、布局高度变化及历史返回；不抢焦点，不随滚动改写URL。移动端展开导航时，使用不会挤动正文上下文的呈现方式。

采用普通链接/可聚焦控件保留键盘路径。核心文字、原图和引用离线可读；脚本失效时仍能顺读正文。宿主有适合的原图/原文定位能力则复用；没有时使用独立HTML，不声称已接入玻尔内部界面。

## 必要的核对

- 阅读正文，检查能否说清主问题、设计理由、关键证据和有限结论；不是只检查标题齐全。
- 对图谱每个节点实际点击，确认目标段落存在、内容回答该问题，来源与当前样品/状态一致。
- 检查图表是否可看清、裁剪是否保留必要信息、SI是否放在有帮助的位置。
- 在实际载体中检查键盘、窄屏、原图展开和离线阅读。核对主干宽度与紧凑分叉高度、侧枝不重叠、左右位置与连线归属。采样真实动画中间帧，验证所有内容始终共存、世界坐标与父节点稳定、仅镜头变换，途中可见来源及目标；再查返回原坐标/比例/焦点、刷新和手动拖拽。查看最终截图及动态实录。未执行的检查写为未验证。
- 读者理解、用时和追问负担需另外记录；模型自评、格式检查和渲染成功不代表阅读增益。


## 整张纸缩放

缩放滑杆与加减控件作用于同一纸面的全部内容，主干、侧枝、图像及连线同步变化且世界坐标保持不变。提供“整张纸”适配当前视窗，以及恢复100%阅读比例。长纸面的最小缩放比例随纸面和视窗尺寸调整；窄屏导航不遮住适配后的纸面。Ctrl加滚轮以指针为中心缩放，普通滚轮的阅读/缩放用途可显式切换。检查指针锚点、滑杆与键盘、全景完整可见、恢复阅读位置及缩放后导航。


## 脑图与画布共用阅读结构

生成一份可检查的节点/连接记录，供脑图及纸面共同使用。主干记录至少含ID、标题、阶段号、图号和目标；侧枝加主干归属、左右方向、侧枝号及来源段落。两边标题与编号一致，图中实线的含义明确为阅读顺序，补读线表示就近细讲；研究论证关系若不同，另作标注，不能将其视为同一拓扑。

脑图点击定位到相同节点，镜头平移、滚轮和缩放后反向标出当前具体侧枝及其主干背景。全文主干始终可概览，当前侧枝可自动展开；全景时不强制选中某一章节。可展开的纸面缩略图反映真实布局和视窗范围，区别于抽象的阅读脑图。核对全部节点的标题/编号/方向/图证、两边连接ID、逐个定位、精确高亮、拖拽/缩放后的视窗框，以及窄屏与键盘。
