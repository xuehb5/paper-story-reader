# 材料与化学的研究问题路线

本文件是编排导读的设计方法，不是所有论文必须符合的科学定律或审稿清单。先找到主贡献与读者的关键理解问题，再选择路线和分支。只提取解释主线需要的细节。

## 材料结构—响应路线

从“在什么条件下希望得到什么表现，现有材料为什么不足”开始。串起设计变量、制备过程、所得样品及状态、结构/性质证据、功能测试和解释。性质与应用表现依论文口径区分，不机械给所有数据分两类。

| 读者的问题 | 导读要解释的连接 | 图与SI的可能角色，按实际材料选择 |
| --- | --- | --- |
| 为什么这样设计材料？ | 目标瓶颈 → 被改变的组分、结构或相互作用 → 预期影响；注明作者设计理由与事后解释 | 分子/组分示意、设计图、必要的已有知识背景 |
| 制备中哪一步有意义？ | 步骤如何影响样品形成；区分原料设计与实际所得结构 | 合成路线、处理示意、SI关键方法；保留影响理解的条件 |
| 是否得到目标对象或状态？ | 哪个结构主张由哪些观测支持；组分、物相、分子结构、形貌和界面等按相关性选择 | 谱图、散射/衍射、显微图、组成数据；SI的结构确认、峰归属或统计 |
| 测试究竟比较什么？ | 样品编号、参照样、测试条件、响应量及其口径 → 结果意味着什么 | 性能曲线、表格、循环或响应图、统计；SI的校准、拟合或重复数据 |
| 哪个变化有助于解释表现？ | 结构/性质证据与响应证据怎样衔接，哪些替代解释被测试，哪些仍未区分 | 对照、原位/非原位观测、计算或模拟；明确模型和实验各自覆盖的对象与条件 |
| 认识能用到哪里？ | 目标之间的权衡、已测范围与外推限制 | 汇总图、适用性数据、失败/稳定性证据；仅在研究确实涉及它们时展开 |

不要因为材料论文有合成部分，就把合成当成全文主要贡献；也不要以仪器出场顺序替代问题推进。若几种方法共同回答一个结构问题，可放在同一问题节点；同一图支持不同判断时可分别引用。

## 化学转化—适用范围路线

从目标转化、合成困难或选择性问题开始，连接设计理由、条件选择、产物确认、转化结果、范围和机制。

| 读者的问题 | 导读要解释的连接 | 图与SI的可能角色 |
| --- | --- | --- |
| 想实现什么转化，难在哪里？ | 被构建/改变的化学连接、目标产物或选择性 → 现有约束 | 反应方案、与已有策略的具体比较 |
| 为什么这个方案值得尝试？ | 催化剂、试剂、底物设计或反应环境的预期作用；区分设计假说与已知结论 | 催化/反应设计示意与相关结构 |
| 条件和关键对照回答了什么？ | 哪个条件有实质影响、如何判断、对照排除了什么；不复述整张优化表 | 条件表、控制实验、关键SI条件；不补充原文未给的配方 |
| 产物是什么，结果怎样测定？ | 结构身份、纯度、构型/区域选择性及定量依据各自如何确认 | 代表性谱图、晶体结构、色谱或SI归属；按实际证据选用 |
| 方法适用于哪些对象？ | 底物变化、反应位点、选择性和产率口径 → 范围与局限 | 底物范围图、分离/检测结果、反例或限制；没有报告失败例不编造失败例 |
| 为什么发生这条路径？ | 哪些观测支持中间体/路径解释，竞争解释是否可区分 | 动力学、标记、捕获、光谱、计算等实际使用的证据；图示路径与观测分开 |

产率、转化率、选择性及不同测定方式先按论文定义，不自动互换。产物确认与机制证明是不同问题。机制研究若不是核心，就用必要的有限解释收束，不人为扩成全面机理审查。

## 混合与跨阶段研究

聚合物、催化和功能分子研究常跨两条路线。围绕同一个主问题组织分支，不按学科标签拆成两篇导读。

- 聚合物：分清单体反应、聚合形成的结构、后处理、测试中的化学变化及最终功能；必要时把不同响应指标并列，避免用一个“性能强弱”替代所有目标。
- 催化材料：催化剂制备和状态证据是一支，催化反应条件与产物/活性选择性是另一支，再由实际证据讨论活性结构与机制。制备后结构不自动等于工作态结构。
- 计算/模拟辅助实验：放在它解释的具体问题旁，说明模型对象、条件与实验对应程度；计算结果不替代未完成的实验验证。

首版不承诺覆盖全部化学与材料子领域。纯理论、纯数据或综述论文需要另行适配；不能因不符合实验路线而捏造合成、表征或性能测试。

## 内部编排的最小关系

先在内部维护一份轻量对应：研究问题 → 具体对象/变量 → 相关观测 → 论文判断 → 导读解释位置 → 图/正文/SI来源。它用于写作与导航一致性，不默认展示成审计表。

样品和状态发生变化时写清对应关系，例如原料、制得样品、处理后样品、测试中和测试后。只在影响当前判断的位置解释尺度、归一化、浓度、温度、介质或模型条件，不堆通用实验参数表。
