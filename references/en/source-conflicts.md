# When the source itself needs care

Read this when a proof/formula, source version, count or central comparison cannot be reconciled from the original material.

First distinguish extraction error from a printed source issue: inspect the original page, including signs, bars/conjugates, exponents, units, legends and footnotes. Do not “repair” a formula from the text layer before viewing it. Preserve the downloaded original and version. Check a linked correction when it affects the explanation; a repository copy may predate it.

Separate three statements: what the source reports, the reader's interpretation, and any calculation/repair made for teaching. Mark a reader-derived bound, counterexample or illustrative scenario as such and verify it. Do not present it as an original result or change the original image. A proof presented by the source is not an independently certified proof; disclose a material gap rather than smoothing it into an unqualified deduction. Use the existing qualified-unit and unresolved-source-issue records to keep such a note visible.

For observational work, count people, repeated records and clusters separately. An adjusted association is not automatically a randomized intervention; non-significance is not zero effect, and a middle category being positive does not make the response monotonic. For synthesis, preserve papers versus estimates versus participants, effect-size units/direction, heterogeneity and uncertainty. A bias adjustment close to the original estimate is not a demonstration that bias does not exist. If the source uses inconsistent notation or flow counts, retain the discrepancy rather than silently creating a clean reconstruction.

For conceptual arguments, attribute the position and preserve its definitions, objections and conditional branches. The author's illustration is not a new experiment, an analogy is not a proof, and a controversial stronger conclusion must not replace the weaker argument the source actually defends.

In the review ledger, use the smallest useful source passage. For JATS with stable element IDs, add `anchor` to text evidence so the validator checks the quote inside that exact element; free-text `locator` remains a human-readable description. Never mark substantive prose, table cells, formulas, captions or graph findings as navigation to escape claim coverage. Headings still require a human check for overclaiming.

Keep source links useful to the reader. When JATS is the machine-readable review source and a matching original PDF is available, use that verified PDF and its physical page for a table/formula reading link rather than requiring the reader to search raw XML. Preserve the anchored JATS evidence as well; do not assign invented PDF pages to it.
